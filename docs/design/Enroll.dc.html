接入一台新服务器

密钥在服务器上生成，私钥不会经过网络，也不会出现在这个面板里。面板只保存公钥。

1

在服务器上安装 agent 并生成密钥

Debian / Ubuntu，用签名过的软件源安装 
curl -fsSL https://pkg.example.com/wanglou.gpg | sudo tee /usr/share/keyrings/wanglou.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/wanglou.gpg] https://pkg.example.com stable main" \
  | sudo tee /etc/apt/sources.list.d/wanglou.list
sudo apt update && sudo apt install wanglou-agent
sudo wanglou-agent init --name {{name}} --server https://ingest.example.com
最后一行会生成 /etc/wanglou/node.key（权限 0400），并打印公钥和指纹。
2

把公钥交给面板
一次性注册码 K7QF-29XM 9:41 后失效 · 用一次即作废
在服务器上运行： 
sudo wanglou-agent enroll K7QF-29XM
注册码只能用来提交公钥，不能读取或修改任何其他数据。
3

核对指纹，然后启用

在服务器上运行 wanglou-agent fingerprint，逐组对比下面的指纹。不一致说明公钥在传递中被替换了，不要启用。
