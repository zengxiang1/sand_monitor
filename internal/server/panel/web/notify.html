如何获取配置

  1. 在 Telegram 中打开 @BotFather，发送 /newbot，按提示创建机器人并取得 token。
  2. 先给机器人发送一条消息，再使用 Telegram API 的 /bot<token>/getUpdates，从返回的 message.chat.id 取得 chat id。群组通常为负数；公开频道也可填写 @频道名。
  3. 填写 token 和 chat id，输入管理员当前验证码并保存，检查确认消息。

验证码用过后需要等待下一个；15 分钟内失败 5 次会暂时锁定修改。API 地址只能在服务器配置中修改。

数据库备份包含明文 token，请妥善保管。
